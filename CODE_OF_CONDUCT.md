# Code of Conduct

This community aims to be welcoming and respectful, following the principles
of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards

Expected behavior includes respectful communication, constructive feedback,
consideration for differing perspectives, and taking responsibility for the
impact of one's words and actions.

Unacceptable behavior includes harassment, discriminatory or demeaning conduct,
personal attacks, unwanted sexual attention, threats, and publishing another
person's private information without permission. Community spaces include
repository issues, pull requests, discussions, and project-related events.

## Reporting and enforcement

Report conduct concerns privately to the repository maintainers. Do not include
private or sensitive details in public issues.

**Maintainers: before public launch, configure and publish a private contact
path for Code of Conduct reports.** No personal contact address is configured
in this repository. Until that path is available, avoid posting sensitive
details publicly; maintainers should update this section as soon as a suitable
reporting route is established.

Maintainers are responsible for reviewing reports fairly and confidentially,
determining appropriate and proportionate responses, and communicating any
enforcement decisions to the people involved where appropriate.
