# Security Policy

## Current security posture

This project is an early in-memory contract foundation. It has **not undergone
a formal security audit**. It has no built-in authentication or authorization,
and it is not a secure storage or deployment service.

Do not submit classified, highly sensitive, confidential, or personal
information to this repository or use it to process such information. Do not
commit credentials, tokens, private data, or real operational evidence.
Treat all external input as untrusted and apply the security controls required
by any system that uses these contracts.

## Reporting a vulnerability

Please do not disclose exploitable details in a public issue or pull request.
If GitHub private vulnerability reporting is enabled for this repository, use
the [private vulnerability reporting page](https://github.com/pepworldOFFICIAL/plaveo-intelligence-/security/advisories/new).
If that page is unavailable, do not post sensitive details publicly.

**Maintainers: configure and verify a private disclosure contact or enable
GitHub private vulnerability reporting before public launch.** No separate
security email or response-time commitment is currently configured.

When reporting privately, include the affected component or commit, impact,
reproduction steps, and any safe suggested mitigation. Avoid including real
secrets or sensitive data in the report.
